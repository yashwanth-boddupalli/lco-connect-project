# LCO CONNECT

Unified Customer & Service Management for Local Connectivity Providers.

One simple platform for customer management, billing, complaints, technicians and local service communication — built for cable, broadband and Wi-Fi operators.

## Project Structure

```
LCO-CONNECT/
│
├── index.html            # Landing page
│
├── pages/                # Future pages (login, register, dashboards)
│
├── css/
│   └── style.css         # Design system & all styles
│
├── js/
│   └── main.js           # UI interactions (nav, FAQ, tabs, scroll)
│
├── assets/
│   ├── images/           # Image assets
│   └── icons/            # Icon assets
│
├── sql/                  # Database schemas (future phases)
│
├── .gitignore
└── README.md
```

## Technology

- HTML5
- CSS3 (vanilla)
- JavaScript (vanilla)
- Google Fonts (Space Grotesk, Inter, IBM Plex Mono)

## Running Locally

Simply open `index.html` in a web browser. No build step required.

Alternatively, use any local server:

```bash
# Python
python -m http.server 8000

# Node.js (if npx available)
npx serve .
```
